AI 시대에 주니어는 어떻게 발전해야 할까
<!--truncate-->

- 인터넷을 보면 opus4.5와 opencode가 엄청나다고 난리였다.
- 점점 에이전틱 코딩에 회의적인 사람의 수가 적어지는 흐름이 보였다.
- 취준생 입장에서 현재 흐름에 어느정도까지 따라가야 할지 고민이 많았다.
- 결론적으로는 AI 툴을 적극 활용하면서 생산성을 향상시키고, 시간을 만들어서 AI 없는 의도적 수련을 하기로 했다.

## Chapter 4. Beyond the 70%: Maximizing Human Contribution
### AI 코딩 어시스턴트는 70프로의 보일러플레이트, 반복 작업을 대신 처리해 준다.
  - 남은 30프로는 인간으로부터 나와야 한다.
  - 복잡한 요구사항 이해
  - 예외 사항 처리
  - 엣지 케이스, 실패 예상
  - 유지보수 가능한 시스템 설계
  - 코드의 정확성 보장
  
    
### 초점은 코드 작성에서 전문 지식 구축으로 발전하여야 한다.
  - 컴포넌트 간의 경계를 이해하자
    - API 설계
    - 이벤트 스키마
    - 데이터 모델
  - 이를 이해하기 위해서는 CS 지식 필요
    - 자료구조, 알고리즘
    - 분산 시스템 원리
    - 디비 내부 구조, 쿼리 최적화
    - 네트워크 프로토콜, 보안
  - 시스템에 대한 이해가 점점 중요해진다.
    - 모니터링, 가시성
    - 성능 프로파일링, 최적화
    - 보안 관행 준수
    - 비용 관리, 최적화
  - 전체 설계
    - 로드 밸런싱, 캐싱 전략
    - 데이터 파티셔닝, 복제
    - 실패 모드, 복구 절차

### 주니어의 발전 방법
- 간단한 CRUD 구현이 빨라짐으로 인해 필요한 것
  - 요구사항을 정확히 명세할 만큼 시스템 아키텍처를 이해
  - 보안 문제, 엣지 케이스 검토하여 코드 검토
  - 구현이 기존 패턴과 일관성을 갖도록 확인
  - 비즈니스 로직 검토하는 **테스트** 작성
- 기본기를 잊지 말자
  - 생성된 코드에 대해 한 줄 한 줄 질문해라
  - 자료구조, 알고리즘, 동시성, 메모리 관리 무조건 이해하라
  - AI 답변은 힌트로 간주하라
  - AI 없는 날을 만들어라
